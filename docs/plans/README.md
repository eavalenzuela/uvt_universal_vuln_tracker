# Plans

Active design plans live at this top level. When a plan is shipped, move it to `done/` and reference it from the matching `## vN.N.N` entry in `docs/CHANGELOG.md`.

`done/` is for historical record only — those plans may be out of date relative to the actual shipped code; trust `docs/BACKEND.md`, `docs/FRONTEND.md`, and the source for current behavior.
